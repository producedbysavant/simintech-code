# Автоматизация SimInTech

Разделы `blocks/`, `patterns/` и `tutorials/` описывают работу в графическом
интерфейсе. Этот раздел — про то, как управлять SimInTech извне: из командной
строки, скриптов и сторонних программ.

| Документ | О чём |
|----------|-------|
| `cli.md` | Запуск `mmain.exe` из командной строки: ключи, переменные окружения, коды возврата |
| `macros.md` | Макроязык: секция `initialization`, объектная модель проекта |
| `file-formats.md` | Форматы файлов: `.prt`, `.xprt`, `.pak`, `.mgr`, `.alt` |
| `codegen.md` | Кодогенерация в C: процедура, типы сигналов, предостережения |
| `signal-db.md` | База сигналов и её экспорт в XML |
| `com-api.md` | COM-интерфейс `IMVTU_Server` (только Windows) |

## Что можно автоматизировать

- **Пакетный расчёт** — прогнать десятки схем без участия человека.
- **Кодогенерация** — получить C-код из моделей в сборочном конвейере.
- **Проверки моделей** — статический анализ схем: неподключённые порты,
  пустые подписи, слишком длинные имена сигналов.
- **Массовая правка** — переименование объектов, переустановка свойств
  по всей схеме.
- **Обмен данными** — выгрузка базы сигналов в XML для внешних инструментов.

## Как выбрать способ

| Задача | Инструмент |
|--------|-----------|
| Разовый запуск, конвейер, CI | Командная строка (`cli.md`) |
| Анализ и правка схем, доступ к объектной модели | Макросы (`macros.md`) |
| Получение C-кода из модели | Кодогенератор (`codegen.md`) |
| Опрос состояния, чтение и запись сигналов «на ходу» | COM-интерфейс (`com-api.md`) |

COM-интерфейс — только Windows. Макросы и командная строка работают всюду,
где запускается сам SimInTech, включая WSL.

## Источники сведений

Материал раздела собран по опыту эксплуатации SimInTech в реальных проектах,
а не переписан из справки. Ключи командной строки, имена макро-команд и
структура форматов проверены на практике. Там, где факт взят только из
документации и не проверялся запуском, это отмечено явно.
