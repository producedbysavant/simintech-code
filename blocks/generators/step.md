# Блок «Ступенька» (Step)

Генерирует сигнал, изменяющийся скачком в заданный момент времени.

## Назначение

Блок «Ступенька» используется для подачи единичного ступенчатого воздействия на систему. Это базовый тестовый сигнал при анализе переходных процессов: по реакции системы на ступеньку можно определить время нарастания, перерегулирование, установившуюся ошибку и другие характеристики.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | — | Нет входов (независимый генератор) |
| Выход | y | Ступенчатый сигнал, double |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| t | double | 0.0 | Момент времени срабатывания, с |
| y0 | double | 0.0 | Значение до срабатывания |
| yk | double | 1.0 | Значение после срабатывания (амплитуда ступеньки) |

> Имена свойств — `t`, `y0`, `yk`. Подтверждено обращением к блоку через
> COM-интерфейс SimInTech.

## Математическое описание

Обозначим текущее время моделирования через τ, чтобы не путать его
с параметром `t`:

```
y(τ) = y0,   τ <  t
y(τ) = yk,   τ >= t
```

## Пример схемы: реакция звена первого порядка на ступеньку

Компоненты:
1. **Ступенька** (t=0.5, y0=0.0, yk=1.0) — входной сигнал
2. **Апериодическое звено 1-го порядка** (K=2.0, T=1.5) — исследуемая система
3. **Временной график** — визуализация

Связи:
```
Ступенька.y  →  Апериод_1.x
Апериод_1.y  →  График.y
Ступенька.y  →  График.x (опционально, для сравнения)
```

Ожидаемый результат: график показывает ступеньку в момент t=0.5 с и экспоненциальный отклик системы, стремящийся к значению K * (yk - y0) = 2.0.

## Код на встроенном языке

```simintech
output y: double;
const
    t = 0.0,     // момент срабатывания
    y0 = 0.0,    // значение до срабатывания
    yk = 1.0;    // значение после срабатывания

begin
    if time < t then
        y = y0
    else
        y = yk;
end;
```

## Варианты использования

- **Единичная ступенька** (y0=0.0, yk=1.0) — анализ переходной характеристики
- **Включение нагрузки** (yk=10.0, t=5.0) — имитация подключения потребителя
- **Сброс возмущения** (yk=-5.0, t=2.0) — имитация снятия возмущающего воздействия
- **Задержанный старт** (y0=0.0, yk=1.0, t=10.0) — запуск процесса через 10 секунд

## Предостережения

- Если t меньше шага моделирования, ступенька сработает на первом же шаге
- При yk = y0 блок не генерирует ступеньку — сигнал остаётся равным y0 на всё время моделирования
- Для генерации последовательности ступенек используйте несколько блоков с разными t и сумматор
- В дискретных моделях ступенька может «проскочить» точку t, если шаг квантования больше расстояния до неё
