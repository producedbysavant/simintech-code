# Блок «Сумматор» (Sum)

Выполняет алгебраическое суммирование нескольких входных сигналов.

## Назначение

Блок «Сумматор» складывает, вычитает и комбинирует сигналы. Это базовый строительный блок любой системы управления: обратные связи, компенсация возмущений, смешивание сигналов, формирование ошибки регулирования.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Входы | in1, in2, ... | Суммируемые сигналы, double |
| Выход | y | Результат суммирования, double |

Количество входов настраивается (от 2 до 10 и более в зависимости от версии).

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| a | array | [1, 1] | Коэффициенты (знаки) входов: +1 «прибавить», −1 «вычесть» |

> Имя свойства — только `a`: знаки задаются не строкой, а массивом
> коэффициентов, и пара знаков «+−» соответствует `a = [1, -1]`. Сверено
> с каталогом `simintech_api/data/block_catalog.json`.
>
> **Число входов свойством не задаётся** — его определяют порты блока:
> `Block.set_in_port_count()` (`SetPortCount`), а в MCP-инструменте
> `add_block` — параметр `in_ports`. Массив `a` задаёт только веса:
> если задать `a` длиннее текущего, коэффициентов станет больше,
> а лишние входы не появятся.

## Математическое описание

```
y = sum(sign_i * in_i)    для всех i = 1..n
```

где sign_i = +1 для знака "+", -1 для знака "-".

## Пример схемы: ПИД-регулятор (формирование ошибки)

Компоненты:
1. **Константа** (a=100.0) — уставка
2. **Ступенька** (yk=20.0, t=3.0) — возмущение
3. **Сумматор** (a=[1, -1]) — формирование ошибки: e = уставка - обратная связь
4. **Временной график** — отображение ошибки

Связи:
```
Константа.y     →  Сумматор.in1  (+)
ОбратнаяСвязь.y →  Сумматор.in2  (-)
Сумматор.y      →  График.y
```

Если у блока три входных порта и `a = [1, 1, -1]`, схема суммирует три входа: y = in1 + in2 - in3.

## Код на встроенном языке

```simintech
input
    in1: double,
    in2: double;
output y: double;
const
    // Знаки входов: +1 — прибавить, -1 — вычесть
    s1 = 1,
    s2 = -1;

begin
    y = s1 * in1 + s2 * in2;
end;
```

## Варианты использования

- **Ошибка регулирования**: `e = setpoint - feedback` (`a = [1, -1]`)
- **Смешивание сигналов**: `y = signal1 + noise` (`a = [1, 1]`)
- **Компенсация**: `y = command + disturbance_compensation` (`a = [1, 1]`)
- **Взвешенная сумма**: задайте коэффициенты в `a`, например `a = [2, 0.5]`
- **Дифференциальный сигнал**: `y = in1 - in2` (`a = [1, -1]`)

## Предостережения

- Длина массива `a` должна совпадать с числом входных портов
- Если вход не подключен, его значение считается нулевым — но лучше явно ставить константу 0
- При одном входе и `a = [1]` блок работает как повторитель
- Большое количество входов снижает читаемость схемы — для сложных комбинаций используйте каскад сумматоров
- Коэффициенты в `a` не ограничены знаками: `a = [2, 0.5]` даёт взвешенную сумму
- При `a = [-1, -1]` выход инвертирует сумму: y = -in1 - in2
