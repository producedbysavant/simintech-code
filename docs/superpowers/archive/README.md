# Архив планов и спецификаций

Здесь лежат планы и спецификации **завершённых** работ. Это журнал замеров и
принятых решений, а не действующий контракт: актуальный контракт живёт в
`docs/api.md`, `docs/reference/` и `docs/evidence/claims.yaml`, а незакрытые
спецификации — в `docs/superpowers/specs/`.

Документы перенесены сюда 2026-09-28 **без правки текста**: изменены только
пути-ссылки. Переписанный задним числом план перестаёт быть доказательством —
по нему нельзя проверить, что именно измеряли и что из этого следовало.
