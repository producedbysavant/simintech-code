# 03. Встроенный язык SimInTech: канон и ловушки

Раздел базы знаний (индекс — `README.md`). **Канон синтаксиса** —
`language/syntax.md` (источник истины; при расхождении с примерами прав
пример), ловушки — `language/pitfalls.md`. Здесь — то, что нужно раньше, чем
открывать канон: где язык исполняется, чего в нём нет и какие границы
проверены живыми прогонами.

## Где какой язык

| Что | Где исполняется | id/источник |
|---|---|---|
| Скрипт страницы (секции `initialization`, шаги расчёта) | Контур моста; создание объектов — **только в `initialization`** | `objects-are-created-only-in-initialization`, `page-script-runs-in-initialization` |
| Скрипт блока «Язык программирования» | Транслируется в C; кодогенерационный чек-лист — скилл `simintech-langblock` | `langblock-port-array-without-size` |
| Макроязык (`/macros`) | Отдельный интерпретатор: там работают `#`, `&`, динамические массивы | `mstarter-macros-runs-macro-in-a-new-instance` |
| Декларативный текст модели | Не скрипт: `object.property = value` — синтаксис текста, в скрипте точка запрещена | `dot-syntax-belongs-to-model-text`, `model-text-loading-creates-objects` |

**Не переносите конструкции между языками.** Самый частый дефект — скрипт
блока, собранный в синтаксисе макроязыка (в справке это разные разделы).

## Формы, проверенные живыми прогонами (в помощь канону)

| id | Факт | Замечание |
|---|---|---|
| `objects-are-created-only-in-initialization` | Создание объектов — только в `initialization`; во время моделирования `createblock` возвращает 0 | Правило подтверждено и ответом поддержки вендора (2026-09-28) |
| `createprimitiv-object-has-no-ports` | Объект из `createprimitiv` появляется **без портов**; порт настраивается `PortNames` + `initobject` | Не «класс не создался» — это штатное состояние неконфигурированного блока |
| `createprimitiv-needs-graphic-container` | `createprimitiv` доступна только в графическом контейнере: из макроса — «функция не найдена» | |
| `tab-is-a-predefined-constant` | `TAB` — предопределённая константа: присваивание в секции ломает компиляцию | Внутри тела собственное имя работает |
| `language-literal-uses-chr34-and-clrf` | Кавычка в литерале — `chr(34)`; перевод строки — `CLRF` (в декларативном тексте — `chr(13) + chr(10)`) | Удвоение `""` даёт пустую строку; обратный слэш не экранирует |
| `model-text-quote-is-chr34` | Тот же `chr(34)` — в тексте модели | Ошибка здесь даёт молчаливое «ничего не создалось» |
| `langblock-port-array-without-size` | Порт-массив блока ЯП объявляется **без размера** (`a: array`); `a[3]: array` даёт неполный набор портов (2 вместо 3) | Ловушка кодогенерации |
| `createmodel-not-in-vendor-help` | `createmodel`, `getinportid`, `getoutportid` применяются в живых измеренных телах, но отсутствуют в реестре имён справки | **Справка отстаёт от среды** — рабочая формула: «есть в репозитории и подтверждено прогоном — значит работает» |

## Ограничения и запреты (перенесено из канона, для предупреждения)

- Зарезервированы имена `i`, `j`, `c` (авто-счётчики транслятора) — в
  кодогенерируемых телах не использовать; запас длины имени бесплатен.
- Цикл — `for (i = a, b)` (форма справки) или проверенный в контурах
  `while`; паскалевская `for i := a to b` не компилируется (живой прогон
  06.10.2026).
- Не транслируются в C: `#`, `&`, `..`, `seterrorstr`, `string`, прямое
  присваивание массивов, матричные операции.
- Строгое сравнение вещественных — источник ошибок: сравнение с допуском
  (`1e-12`) и `sqrt(abs(x))` — из правил кодогенерации (скилл
  `simintech-langblock`, чек-лист).

## Функции: где брать точные имена

Реестр `simintech_api/data/language_functions.json` — срез справки поставки
(схема 2: имя, назначение, синтаксис, аргументы). У агента — MCP-инструменты
`search_language_functions`/`get_language_function` и ресурс
`simintech://language/functions`.

**Важно (см. `createmodel-not-in-vendor-help`):** отсутствие имени в реестре
ничего не опровергает — реестр собран из справки, а справка отстаёт; и
наоборот, имя в реестре — ещё не живая проверка. Основания в порядке доверия:
живой прогон → поставка → справка.

## Чего раздел не заменяет

Справочника по всем функциям здесь нет и не будет — их 907 в реестре и
страницы справки на каждую. Раздел отвечает на «что сломается, если этого не
знать»; полный синтаксис — `language/syntax.md`, конкретная функция —
`simintech_api.language.find_function(name)`.
