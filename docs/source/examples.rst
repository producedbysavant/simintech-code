Примеры использования
=====================

Готовые примеры лежат в ``examples/`` и запускаются на Windows
(требуют ``mmain.exe /regserver``). Примеры, которые считают, создают проект
из шаблона (``Project.from_template``): у проекта из ``Project.new()`` нет
расчётного слоя, и модельное время в нём не растёт.

Модель 1: «Усилитель сигнала»
-----------------------------

.. code-block:: bash

   python examples/model1_amplifier.py

Схема: ``Синусоида (1 Гц, амплитуда 1) → Усилитель (×2.5)``. Расчёт на
10 секунд с проверкой возврата ``run_to``, сохранение схемы в XML.

Модель 2: «ПИД-регулятор»
-------------------------

.. code-block:: bash

   python examples/model2_pid.py

``Ступенька → Сумматор ошибки → ПИД-ветви (Kp/Ki/Kd) → Интегратор (объект)``
с обратной связью выхода на вход сумматора. Сборка схемы без расчёта: проект
создаётся через ``Project.new()``, а выгрузка переходной характеристики
требует чтения сигналов через COM, которое недоступно, — пример сообщает об
этом и останавливается.

Модель 3: «Многокомпонентная система»
-------------------------------------

.. code-block:: bash

   python examples/model3_complex.py

12 блоков, 14 перекрёстных связей. ``LayeredPlacer`` расставляет блоки без
наложений, линии создаются без опорных точек — маршрут задаёт SimInTech.
Выводит координаты блоков и идентификаторы линий.

Jupyter Notebook
----------------

.. code-block:: bash

   jupyter notebook examples/demo.ipynb

12 ячеек: подключение COM, модели 1–2, модель 3 (layout).
Ячейки COM работают на Windows; layout-ячейки — в любом окружении.
