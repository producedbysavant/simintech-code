# ПИД-регулятор

## Описание

ПИД-регулятор (пропорционально-интегрально-дифференциальный) — самый распространённый регулятор в промышленности. Используется для управления температурой, скоростью, положением и другими параметрами.

## Передаточная функция

```
W(s) = Kp + Ki/s + Kd*s
```

## Реализация в SimInTech

### Вариант 1: Блок «Язык программирования»

Канонический синтаксис (см. `language/syntax.md`). Шаг расчёта — системная
переменная `stepsize`. Коэффициенты и ограничения заданы константами блока:

```simintech
input
    setpoint: double,
    measurement: double;
output control: double;

const
    Kp = 1.5,      // пропорциональный коэффициент
    Ki = 0.8,      // интегральный коэффициент
    Kd = 0.3,      // дифференциальный коэффициент
    uMax = 10.0,   // максимальное управление
    uMin = -10.0;  // минимальное управление

var
    error: double,
    prevError: double,
    integral: double,
    pTerm: double,
    iTerm: double,
    dTerm: double,
    uRaw: double,
    saturated: boolean;

begin
    // Ошибка регулирования
    error = setpoint - measurement;

    // П-составляющая
    pTerm = Kp * error;

    // И-составляющая (трапецеидальное интегрирование, anti-windup:
    // интегрируем только тогда, когда регулятор не в насыщении)
    if saturated = false then
        integral = integral + (error + prevError) * stepsize / 2.0;
    iTerm = Ki * integral;

    // Д-составляющая
    dTerm = Kd * (error - prevError) / stepsize;

    // Суммарное управление
    uRaw = pTerm + iTerm + dTerm;

    // Ограничение управления + признак насыщения
    if uRaw > uMax then
    begin
        control = uMax;
        saturated = true;
    end
    else if uRaw < uMin then
    begin
        control = uMin;
        saturated = true;
    end
    else
    begin
        control = uRaw;
        saturated = false;
    end;

    prevError = error;
end;
```

На первом шаге `prevError` равно нулю, поэтому Д-составляющая даёт «рывок» на
скачке задания. Если это нежелательно, добавь фильтр низких частот на вход
`measurement` либо задавай уставку плавно.

### Вариант 2: Схема из блоков

1. **Блоки-источники**: Константа (setpoint), Константа (measurement)
2. **Сумматор** (setpoint − measurement) → ошибка
3. **Усилитель** (Kp) → P-ветвь
4. **Интегратор** (Ki/s) → I-ветвь
5. **Дифференциатор** (Kd·s) → D-ветвь
6. **Сумматор** (P + I + D) → управление

## Расчёт коэффициентов

### Метод Циглера-Никольса (колебательный)

1. Установить Ki = 0, Kd = 0
2. Увеличивать Kp до появления незатухающих колебаний → Ku (критический коэффициент)
3. Измерить период колебаний → Tu
4. Рассчитать:

| Тип | Kp | Ki | Kd |
|-----|----|----|-----|
| P | 0.5·Ku | — | — |
| PI | 0.45·Ku | 0.54·Ku/Tu | — |
| PID | 0.6·Ku | 1.2·Ku/Tu | 0.075·Ku·Tu |

## Типичные ошибки

1. **Интегральное насыщение (windup)** — интеграл растёт до бесконечности → anti-windup защита
2. **Шум в D-составляющей** — усиление шума датчика → фильтр НЧ на входе D-ветви
3. **Слишком большой шаг интегрирования** — при большом `stepsize` интегрирование расходится → уменьшить шаг моделирования
4. **Знак ошибки** — перепутаны setpoint и measurement → проверить полярность
5. **Д-составляющая при нулевом шаге** — деление на `stepsize` требует ненулевого шага; при фиксированном шаге расчёта `stepsize` > 0, но при переменном шаге защищайте знаменатель (см. `language/syntax.md`)

## Тестирование

Подать на вход ступенчатый сигнал (блок «Ступенька»). Оценить:
- Время переходного процесса (до 5% от установившегося значения)
- Перерегулирование (%)
- Статическая ошибка (должна быть 0 при наличии I-составляющей)
