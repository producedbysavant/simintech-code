# Контур обратной связи (Feedback Loop)

Замкнутая система управления, в которой выход системы влияет на вход через обратную связь.

## Назначение

Контур обратной связи — фундаментальная концепция теории управления. Суть проста: измеряем выход системы, сравниваем с желаемым значением (уставкой) и корректируем управление. Это позволяет:

- Компенсировать возмущения
- Уменьшать влияние неопределённости модели
- Стабилизировать неустойчивые системы
- Улучшать динамические характеристики

## Структура контура

```
                  +       error
Уставка (SP) --->(+)----->[Регулятор]--->[Объект]---> Выход (PV)
                 ^(-)                     |
                 |                        |
                 +-----[Датчик]<----------+
```

Основные элементы:
- **Уставка (Setpoint, SP)**: желаемое значение регулируемой величины
- **Ошибка (Error)**: разность между уставкой и измеренным значением: e = SP - PV
- **Регулятор (Controller)**: формирует управляющий сигнал по закону П, ПИ, ПИД и т.д.
- **Объект управления (Plant)**: система, которой мы управляем
- **Датчик (Sensor)**: измеряет выход и преобразует в сигнал обратной связи
- **Возмущение (Disturbance)**: внешнее воздействие, которое контур должен компенсировать

## Математическое описание

### Передаточная функция замкнутого контура

```
W_closed(s) = G(s) / (1 + G(s) * H(s))
```

где:
- G(s) — передаточная функция прямой цепи (регулятор + объект)
- H(s) — передаточная функция цепи обратной связи (датчик)

При единичной обратной связи (H(s) = 1):
```
W_closed(s) = G(s) / (1 + G(s))
```

### Чувствительность к возмущениям

```
S_d(s) = 1 / (1 + G(s))
```

Чем больше усиление в прямой цепи, тем меньше влияние возмущения на выход.

## Пример схемы: стабилизация температуры

Компоненты:
1. **Константа** (y0=100.0) — уставка температуры
2. **Сумматор** (a=[1, -1]) — формирование ошибки
3. **ПИД-регулятор** — закон управления
4. **Передаточная функция** (num=[1.5], den=[10, 1]) — объект (печь): инерционное звено
5. **Передаточная функция** (num=[1], den=[0.5, 1]) — датчик температуры
6. **Ступенька** (yk=10.0, t=20.0) — возмущение (открытие дверцы)
7. **Сумматор_2** (a=[1, 1]) — добавление возмущения к выходу объекта
8. **Временной график** — уставка, выход, возмущение

Связи:
```
Уставка       →  Сумматор_1.in1 (+)
ВыходДатчика  →  Сумматор_1.in2 (-)
Сумматор_1.y  →  ПИД.setpoint
ПИД.output    →  Объект.u
Объект.y      →  Сумматор_2.in1 (+)
Возмущение    →  Сумматор_2.in2 (+)
Сумматор_2.y  →  Датчик.u
Датчик.y      →  (обратная связь на Сумматор_1.in2)
```

## Реализация в SimInTech: прямой код

Ниже регулятор и объект описаны внутри одного блока «Язык программирования».
Синтаксис — канонический (см. `language/syntax.md`); шаг расчёта — `stepsize`,
время — `time`. Обратная связь замкнута через выход `processVariable`, поэтому
на каждом шаге используется его значение с предыдущего шага.

```simintech
input setpoint: double;
output processVariable: double;

const
    // Объект: апериодическое звено 1/(10s+1)
    plantTc = 10.0,
    plantGain = 1.5,

    // Регулятор (ПИД)
    Kp = 2.5,
    Ki = 0.3,
    Kd = 0.05,

    // Возмущение: ступенька в момент distTime
    distTime = 20.0,
    distAmp = 10.0;

var
    plantState: double,
    integral: double,
    prevError: double,
    disturbance: double,
    error: double,
    controlSignal: double,
    saturated: boolean;

begin
    // Возмущение: ступенька в момент time = distTime
    if time >= distTime then
        disturbance = distAmp
    else
        disturbance = 0.0;

    // Ошибка регулирования
    error = setpoint - processVariable;

    // П-составляющая
    controlSignal = Kp * error;

    // И-составляющая (anti-windup: интегрируем только вне насыщения)
    if saturated = false then
        integral = integral + error * stepsize;
    controlSignal = controlSignal + Ki * integral;

    // Д-составляющая
    controlSignal = controlSignal + Kd * (error - prevError) / stepsize;

    // Ограничение управляющего сигнала
    if controlSignal > 100.0 then
    begin
        controlSignal = 100.0;
        saturated = true;
    end
    else if controlSignal < 0.0 then
    begin
        controlSignal = 0.0;
        saturated = true;
    end
    else
        saturated = false;

    // Объект: явный Эйлер для 1/(10s+1)
    plantState = plantState + (plantGain * controlSignal - plantState) / plantTc * stepsize;

    // Выход (с возмущением) — он же сигнал обратной связи
    processVariable = plantState + disturbance;

    prevError = error;
end;
```

## Анализ устойчивости замкнутого контура

### Критерий Найквиста

Замкнутая система устойчива, если годограф разомкнутой системы W(s) = G(s)*H(s) не охватывает точку (-1, j0).

### Критерий Михайлова

Замкнутая система устойчива, если характеристический полином 1 + G(s)*H(s) имеет все корни в левой полуплоскости.

### Запасы устойчивости

| Параметр | Минимальное значение | Рекомендуемое значение |
|----------|---------------------|----------------------|
| Запас по фазе | > 0° | 30° — 60° |
| Запас по амплитуде | > 0 дБ | 6 — 12 дБ |

## Варианты контуров обратной связи

### По выходу (основной)
```
Регулятор → Объект → Датчик → (обратная связь на регулятор)
```

### По возмущению (прямая связь + обратная)
```
Измеряем возмущение и компенсируем его до того, как оно повлияет на выход.
```

### Каскадный
```
Внешний контур (медленный) → Внутренний контур (быстрый) → Объект
```

Пример: контур температуры (медленный) управляет уставкой контура расхода (быстрый).

### Комбинированный
```
Обратная связь + прямая связь по возмущению.
```

## Предостережения

- Отрицательная обратная связь стабилизирует, положительная — дестабилизирует (обычно). Убедитесь, что знак обратной связи правильный
- Запаздывание в цепи обратной связи (запаздывание датчика) уменьшает запас по фазе и может привести к потере устойчивости
- Высокое усиление в прямой цепи снижает статическую ошибку, но ухудшает запас устойчивости — компромисс неизбежен
- Ограничение управляющего сигнала (насыщение) размыкает контур обратной связи — следует применять анти-windup
- Шум измерения датчика передаётся в управляющий сигнал с коэффициентом усиления регулятора — фильтруйте сигнал датчика
- При моделировании всегда включайте в контур датчик — его динамика влияет на устойчивость
- Начинайте настройку с низких коэффициентов и постепенно увеличивайте — так вы не «уроните» систему
- Слишком большой шаг `stepsize` относительно постоянных времени контура делает явный Эйлер неустойчивым — уменьшайте шаг
