# Модель в пространстве состояний (State-Space Model)

Представление динамической системы в форме дифференциальных уравнений первого порядка.

## Назначение

Модель в пространстве состояний — это способ описания динамической системы с помощью n дифференциальных уравнений первого порядка, сведённых в векторно-матричную форму. В отличие от передаточной функции, пространство состояний позволяет:

- Моделировать многомерные системы (MIMO — Multiple Input Multiple Output)
- Учитывать ненулевые начальные условия
- Анализировать внутреннюю структуру системы (наблюдаемость, управляемость)
- Моделировать нелинейные системы

## Математическое описание

### Линейная стационарная система

```
dX/dt = A * X + B * u
Y     = C * X + D * u
```

где:
- X — вектор состояния (n x 1)
- u — вектор входов (m x 1)
- Y — вектор выходов (p x 1)
- A — матрица динамики (n x n)
- B — матрица управления (n x m)
- C — матрица наблюдения (p x n)
- D — матрица обхода (p x m)

### Пример: масса-пружина-демпфер

Уравнение движения:
```
m * d2x/dt2 + c * dx/dt + k * x = F(t)
```

Выберем переменные состояния:
```
X1 = x (положение)
X2 = dx/dt (скорость)
```

Тогда:
```
dX1/dt = X2
dX2/dt = (-k/m) * X1 + (-c/m) * X2 + (1/m) * F(t)
```

В матричной форме:
```
A = [0,      1    ]
    [-k/m,  -c/m  ]

B = [0  ]
    [1/m]

C = [1, 0]  (наблюдаем положение)

D = [0]
```

## Реализация в SimInTech: схема

Компоненты:
1. **Константы** — параметры m, c, k
2. **Интегратор_1** — X1 (положение)
3. **Интегратор_2** — X2 (скорость)
4. **Усилители** — умножение на коэффициенты -k/m, -c/m, 1/m
5. **Сумматоры** — формирование dX2/dt
6. **Временной график** — визуализация

Связи (численные при m=1, c=0.5, k=2):
```
Сила_F        →  Усилитель_F (a=1.0)     →  Сумматор_dX2.in1 (+)
Интегратор_2.y  →  Усилитель_damp (a=-0.5) →  Сумматор_dX2.in2 (-)
Интегратор_1.y  →  Усилитель_spring (a=-2.0) →  Сумматор_dX2.in3 (-)
Сумматор_dX2.y  →  Интегратор_2.u
Интегратор_2.y  →  Интегратор_1.u
```

## Реализация в SimInTech: код на встроенном языке

Матричные операции (`*`, `\`, `./`) **не кодогенерируются в C**, поэтому
умножение матриц реализовано вложенными циклами. Массивы индексируются **от 1**,
размерность задаётся статически. Начальные условия — нулевые (переменные из
`var` обнуляются при старте); матрицы коэффициентов заполняются один раз по
флагу `initialized` (см. `language/keywords.md`). Шаг — `stepsize`.

> Матрица наблюдения названа `Cout`, а не `C`: имя `c` (в любом регистре)
> зарезервировано транслятором под служебный счётчик, и переменная с таким
> именем не соберётся. Остальные матрицы — `A`, `B`, `D` — конфликтов не дают.

```simintech
// Вход: вектор u (m=2). Выход: вектор y (p=2). Система 3-го порядка (n=3).
input u[2]: array;
output y[2]: array;

const
    NX = 3,   // порядок системы
    NU = 2,   // число входов
    NY = 2;   // число выходов

var
    A[NX, NX]: array,
    B[NX, NU]: array,
    Cout[NY, NX]: array,
    D[NY, NU]: array,
    X[NX]: array,      // состояние
    dX[NX]: array,     // производные
    row: integer,
    col: integer,
    initialized: boolean;

begin
    // Однократное заполнение матриц коэффициентов
    if initialized = false then
    begin
        A[1,1] = -0.5;  A[1,2] =  0.0;  A[1,3] =  1.0;
        A[2,1] =  0.0;  A[2,2] = -1.0;  A[2,3] =  0.5;
        A[3,1] = -2.0;  A[3,2] =  0.0;  A[3,3] = -0.3;

        B[1,1] =  1.0;  B[1,2] =  0.0;
        B[2,1] =  0.0;  B[2,2] =  1.0;
        B[3,1] =  0.5;  B[3,2] =  0.0;

        Cout[1,1] =  1.0;  Cout[1,2] =  0.0;  Cout[1,3] =  0.0;
        Cout[2,1] =  0.0;  Cout[2,2] =  0.0;  Cout[2,3] =  1.0;

        D[1,1] =  0.0;  D[1,2] =  0.0;
        D[2,1] =  0.0;  D[2,2] =  0.0;

        initialized = true;
    end;

    // dX = A*X + B*u
    for (row = 1, NX) do
    begin
        dX[row] = 0.0;
        for (col = 1, NX) do
            dX[row] = dX[row] + A[row, col] * X[col];
        for (col = 1, NU) do
            dX[row] = dX[row] + B[row, col] * u[col];
    end;

    // y = Cout*X + D*u
    for (row = 1, NY) do
    begin
        y[row] = 0.0;
        for (col = 1, NX) do
            y[row] = y[row] + Cout[row, col] * X[col];
        for (col = 1, NU) do
            y[row] = y[row] + D[row, col] * u[col];
    end;

    // Интегрирование (явный Эйлер)
    for (row = 1, NX) do
        X[row] = X[row] + dX[row] * stepsize;
end;
```

Матрицу `A` можно не заполнять вручную, если задать её формулами, но прямое
присваивание массивов (`A = ...`) в C не транслируется — заполняй поэлементно.

## Анализ свойств системы

### Управляемость

Система управляема, если матрица управляемости
```
Uc = [B, A*B, A^2*B, ..., A^(n-1)*B]
```
имеет полный ранг (rank = n).

### Наблюдаемость

Система наблюдаема, если матрица наблюдаемости
```
Uo = [C; C*A; C*A^2; ...; C*A^(n-1)]
```
имеет полный ранг (rank = n).

### Устойчивость

Система устойчива, если все собственные числа матрицы A имеют отрицательные вещественные части (находятся в левой полуплоскости).

## Переход от передаточной функции к пространству состояний

Дана передаточная функция:
```
W(s) = (b_2*s^2 + b_1*s + b_0) / (s^3 + a_2*s^2 + a_1*s + a_0)
```

Форма управляемого канонического представления:
```
A = [0,   1,   0]
    [0,   0,   1]
    [-a0, -a1, -a2]

B = [0]
    [0]
    [1]

C = [b0, b1, b2]

D = [0]
```

## Варианты использования

- **Моделирование механических систем**: масса-пружина-демпфер, маятник, робот-манипулятор
- **Электрические цепи**: RLC-цепи, фильтры, линии передачи
- **Термодинамика**: тепловые процессы, теплообменники
- **Аэрокосмические системы**: динамика полёта, ориентация спутника
- **Модальный синтез**: управление с размещением полюсов (pole placement)
- **Наблюдатели**: оценка недоступных измерению переменных состояния

## Предостережения

- Размерность вектора состояния n определяет сложность модели — каждое дополнительное состояние добавляет дифференциальное уравнение
- Матрица A должна быть квадратной (n x n) — ошибка в размерности приводит к некорректным результатам
- При численном интегрировании жёстких систем шаг `stepsize` должен быть достаточно мал, иначе решение расходится
- Для нелинейных систем матрицы A, B, C, D зависят от состояния — используйте линеаризацию в окрестности рабочей точки
- Проверяйте управляемость и наблюдаемость перед синтезом регулятора — если система неуправляема, никакой регулятор не поможет
- В дискретном времени матрицы перехода отличаются от непрерывных — дискретизацию выполняй по своей схеме (например, явный Эйлер с шагом `stepsize`); готовой функции `c2d` в языке нет
- Матричные операции и прямое присваивание массивов не кодогенерируются — все вычисления оформляй циклами
