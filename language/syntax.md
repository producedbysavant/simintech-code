# Синтаксис языка SimInTech

Код блока «Язык программирования» исполняется на каждом расчётном шаге.
Блоки транслируются в C — код должен быть пригоден для кодогенерации.

## Ключевые слова

| Ключевое слово | Назначение | Пример |
|---------------|------------|--------|
| `input` | Входная переменная блока | `input u: double;` |
| `output` | Выходная переменная блока | `output y: double;` |
| `const` | Константа | `const g = 9.81;` |
| `var` | Переменная (сохраняется между шагами) | `var counter: integer;` |
| `begin..end` | Блок кода | `begin ... end;` |
| `finalization` | Секция завершения расчёта | `finalization ... end;` |

## Структура программы

Объявления идут до тела расчёта, в таком порядке: входы → выходы → константы →
переменные → подпрограммы. Тело расчёта выполняется каждый шаг; необязательная
секция `finalization` — один раз по окончании расчёта.

```simintech
input u: double;
output y: double;
const K = 2.5;

var state: double;

begin
    state = state + u * hmax;
    y = K * state;
finalization
    // закрыть файлы, выгрузить накопленные данные
end;
```

`finalization` — единственное место, где уместны операции, которые нельзя
повторять на каждом шаге: запись итогового лога, закрытие файла, освобождение
ресурсов.

## Правила

- `;` — конец оператора
- `{ }` — блочный комментарий
- `//` — комментарий до конца строки
- Идентификаторы: латиница + кириллица + цифры + `_`
- **Регистр НЕ различается**: `Speed` = `speed`
- **Каждая переменная с явным типом**: `var a: double, b: double;`
- **Запрещены имена `i`, `j`, `c`** — конфликтуют с авто-счётчиками транслятора

## Типы данных

| Тип | Описание | Кодогенерация |
|-----|----------|---------------|
| `double` | Вещественное число (64 бит) | ✅ |
| `integer` | Целое число | ✅ |
| `boolean` | Логическое значение | ✅ |
| `array` | Массив вещественных чисел | ✅ (только статический) |
| `intarray` | Массив целых чисел | ✅ (только статический) |
| `string` | Строка | ❌ |

Объявление массивов:
```simintech
const MAX = 100;
var
    R[MAX]: array,
    indices[MAX]: intarray;
```

## Операторы

Арифметические: `+ - * /` и `div` (целочисленное), `mod` (остаток)
Сравнения: `= <> < > <= >=` (НЕ `==`, НЕ `!=`)
Логические: `and or xor` (оператор `not` НЕ поддерживается — отрицание через `X = false` / `X <> true`)
Битовые: `shl shr`

## Управляющие конструкции

```simintech
if x > 0 then
begin
    y = sqrt(x);
end
else
begin
    y = 0;
end;
```

```simintech
for (idx = 1, N) do
begin
    arr[idx] = idx * hmax;
end;
```

```simintech
while error > tolerance do
begin
    error = error * 0.5;
    iter = iter + 1;
    if iter >= 50 then break;
end;
```

## Встроенные функции

`sin cos tan asin acos atan exp ln log10 sqrt abs sign pow mod`
`min max sum mean size round floor ceil`
`lengthofm` — длина массива; `length` — длина строки

Файловые операции: `createfile`, `fileexists`, `seek`, `filesize`, `writelnutf8`.
Строковые: `strcopy`, `pos`, `lowercase`, `floattostr`.

## Пользовательские функции и процедуры

Поддерживаются `function`/`procedure` (см. webhelp «Подпрограммы»):

```simintech
function SumQ(A, out R: integer): double
    SumQ = sqr(A);        // возврат — присваивание имени функции
    R = round(SumQ);
end;
```

- Внутренние переменные функции при стандартном вызове **общие для всех вызовов**; для отдельных — модификатор вызова `|inline`.
- Выходные параметры декларируются словом `out`.

## Системные переменные (read-only)

| Переменная | Описание |
|------------|----------|
| `time` | Текущее время моделирования (сек) |
| `hmax` / `hmin` | Текущий шаг расчёта (сек); при фиксированном шаге `hmax` = `hmin` |

> ⚠ Переменные `T`, `dt`, `Nstep`, `Tstop` системными **не являются** (ошибочно указаны в ранних версиях этого документа). Полный перечень системных переменных — в справке SimInTech (webhelp), раздел «Переменные → Системные переменные».

## Важные замечания

1. Код выполняется на каждом шаге — не используй бесконечные циклы
2. `var` сохраняет значение между шагами (в отличие от интерпретатора)
3. Размерности массивов фиксированы — избегай динамических массивов
4. Нет динамической памяти
5. После изменений запускай кодогенерацию — «Инструменты» → «Сгенерировать
   программу» — и разбирай сообщения в окне вывода
6. `#`, `&`, `..` не транслируются в C — используй циклы
