# Синтаксис языка SimInTech

Код блока «Язык программирования» исполняется **на каждом расчётном шаге**.

## Ключевые слова

| Ключевое слово | Назначение | Пример |
|---------------|------------|--------|
| `input` | Входная переменная блока | `input u;` |
| `output` | Выходная переменная блока | `output y;` |
| `const` | Константа | `const g = 9.81;` |
| `var` | Алгебраическая переменная (сбрасывается каждый шаг) | `var temp;` |
| `init` | Динамическая переменная (сохраняется между шагами) | `init counter = 0;` |

## Правила

- `;` — конец оператора
- `{ }` — блочный комментарий
- `//` — комментарий до конца строки
- Идентификаторы: латиница + кириллица + цифры + `_`
- **Регистр НЕ различается**: `Speed` = `speed`

## Типы данных

- `double` — 64-bit float (основной)
- Массивы: `var x[10];`
- Матрицы: `var A[3, 3];`
- Строки: `var msg = "текст";`

## Операторы

Арифметические: `+ - * / ^ %`
Сравнения: `== != < > <= >=`
Логические: `&& || !`

## Управляющие конструкции

```c
if (x > 0) {
    y = sqrt(x);
} else {
    y = 0;
}

for (i = 0; i < 10; i++) {
    arr[i] = i * h;
}

while (error > tolerance) {
    error = error * 0.5;
}
```

## Встроенные функции

`sin cos tan asin acos atan exp ln log10 sqrt abs sign pow mod`
`min max sum mean size`

## Предопределённые переменные

- `h` — шаг интегрирования (read-only)
- `t` — текущее время моделирования (read-only)

## Важные замечания

1. Код выполняется на каждом шаге — не используй бесконечные циклы
2. `var` сбрасывается каждый шаг, `init` сохраняет значение
3. Размерности массивов фиксированы
4. Нет динамической памяти
