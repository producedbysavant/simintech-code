# Contributing to SimInTech Code Library

Спасибо за интерес к проекту! Мы строим первую открытую библиотеку кода для SimInTech, и каждый вклад ценен.

## Как можно помочь

### 1. Добавить документацию блока

Если вы разобрались с блоком, которого нет в библиотеке — напишите документацию по шаблону:

```markdown
## Назначение
## Входы и выходы
## Параметры
## Пример схемы
## Код (если применимо)
## Предостережения
```

### 2. Исправить ошибку

Нашли неточность? Создайте Issue или PR с исправлением. Особенно важны:
- Неправильные названия параметров
- Ошибки в формулах
- Некорректный код на встроенном языке

### 3. Добавить пример

У вас есть работающая модель, которую вы хотите показать сообществу? Добавьте её в `patterns/` или `tutorials/`.

### 4. Перевод

Если вы хотите перевести документацию на другой язык — создайте Issue с обсуждением структуры.

## Процесс

1. Форкните репозиторий
2. Создайте ветку: `git checkout -b feature/my-contribution`
3. Внесите изменения
4. Убедитесь, что файлы следуют единому шаблону
5. Создайте Pull Request с описанием изменений

## Стайлгайд

- Язык: русский (термины и код — английские)
- Каждый блок — отдельный `.md`-файл
- Следуйте шаблону документации блока
- Код на встроенном языке SimInTech должен быть рабочим
- Примеры схем — в виде ASCII-схем или описания связей между блоками

## Что не принимается

- Реклама коммерческих продуктов
- Непроверенная информация
- Спам
